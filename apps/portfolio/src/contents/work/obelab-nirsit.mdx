## 배경

NIRSIT는 fNIRS 기반의 웨어러블 뇌영상 측정기기다. 이 기기가 만드는 환자·검사 데이터를 의사가 웹에서 관리하고, 모바일 앱이 원본 분석 파일을 업로드·다운로드할 수 있게 하는 시스템을 만들었다. PL로서 전체 설계·DB 설계·API 설계와 문서화를 주도했고, 앱 클라이언트와 그래프 시각화 엔진은 담당 범위 밖이었다.

## 소비자가 둘인 API를 설계하다

같은 데이터를 의사 웹과 모바일 앱이 서로 다른 목적으로 소비하는 구조라, API를 `/app/*`(모바일)과 `/doctor/*`(의사 웹)로 역할별 분리하고 Swagger로 문서화해 협업 접점을 명확히 했다. 실시간 알림은 WebSocket 기반 Push로 구현했다.

데이터 모델에서는 검사 종류가 boolean 컬럼으로 하나씩 굳어 있던 스키마를 **카테고리 코드 테이블 구조로 리팩터링**했다 — 새 검사 종류가 생길 때마다 스키마를 바꾸는 대신, 행을 추가하면 되는 구조로 확장성을 확보했다.
