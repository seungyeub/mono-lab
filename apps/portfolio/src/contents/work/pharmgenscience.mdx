## 배경

제약회사 팜젠사이언스의 신규 반응형 홈페이지와 관리자페이지를 구축하는 프로젝트였다. 화면만 새로 만드는 것이 아니라, 레거시 사이트(MySQL)의 데이터를 신규 플랫폼(PostgreSQL)으로 이관하는 것까지가 범위였다. PL로서 견적·계약 협상부터 납품까지 전체를 총괄했고, 그중 프론트엔드는 전체를 직접 개발했다 — 백엔드와 DB 이관은 팀원 담당으로, 직접 구현과 총괄 범위를 구분해 둔다.

## 반복되는 화면을 계층으로 눌러 담다

기업 홈페이지는 게시판·제품 목록·상세처럼 구조가 반복되는 화면이 많다. `apis → hooks → templates` 3단 계층을 세우고 클라이언트 상태(Recoil)와 서버 상태(react-query)를 이원화해, 공통 템플릿을 도메인마다 재사용하는 구조로 설계했다.

다국어(한/영)는 next-i18next로 지원했고, Google Maps·공공데이터포털·KOSCOM API를 연동한 데이터 시각화는 @ant-design/plots로 구성했다. 배포는 `next export` 정적 방식을 채택했다.
