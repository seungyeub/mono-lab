> **작성일:** 2026-09-02
> **Title:** 프로젝트별 코드 스니펫·이미지 요청 목록
> **Description:** 상세 페이지 리디자인(P1-1 D-2)으로 슬롯은 준비 완료. 아래 자료가 채워지는 프로젝트부터 해당 영역이 자동 활성화된다(조건부 렌더링). 전달 형식은 자유 — 코드는 붙여넣기, 이미지는 파일 전달이면 되고, frontmatter 기입·파일 배치는 작업자가 수행한다.

- 함께 필요한 것: 이 코드가 무엇을 보여주는지 **한 줄 설명**(`codeCaption`)
- 클라이언트 소스는 공개 범위를 직접 판단해 주세요 — 식별자·URL·키는 마스킹 가능

## 2. 이미지

파일명은 자유. 어떤 프로젝트의 어떤 용도인지만 알려주면 배치·frontmatter 기입은 작업자가 한다.
**개인정보·계정정보·내부 데이터가 보이는 화면은 마스킹 후 전달.**

### 2-1. Hero 캐러셀 (`carouselImages`) — 상세 페이지 상단 프레임 카드

- 비율 **가로 16:10** (다른 비율도 수용 — object-cover로 크롭됨), 폭 **1280px 이상** 권장
- 프로젝트당 **1~5장** (1장이면 정지, 2장 이상이면 3초 자동 순환)
- 대표 화면·메인 플로우 위주

### 2-2. 카드 대표 이미지 (`image`) — 홈/`/work` 목록/More Works 카드

- 비율 **세로 3:4** (홈 좌열은 4:5 — 세로형이면 둘 다 수용), 폭 **1200px 이상** 권장
- 프로젝트당 1장. 경로는 frontmatter에 `/images/projects/{slug}.jpg`로 이미 지정돼 있음

### 2-3. Demonstrations (`demonstrations[].images`) — 기능 흐름 시연

- 비율 **4:3**, 데모 항목당 **1~5장** (2장 이상이면 자동 순환)
- 데모 단위 = "하나의 사용 흐름" (예: 검색→상세→결과). 이미지와 함께 흐름 설명 불릿·결과 한 줄이 있으면 이상적
- 카드 초안 메모 참고: KTI는 보유 캡쳐가 현행과 달라 라이브 사이트 재캡쳐 가능, YogaEditor는 기존 캡쳐 품질 문제로 미사용 결정(대표 이미지 별도 제작 가능)
