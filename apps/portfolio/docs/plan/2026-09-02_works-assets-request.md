> **작성일:** 2026-09-02
> **Title:** 프로젝트별 코드 스니펫·이미지 요청 목록
> **Description:** 상세 페이지 리디자인(P1-1 D-2)으로 슬롯은 준비 완료. 아래 자료가 채워지는 프로젝트부터 해당 영역이 자동 활성화된다(조건부 렌더링). 전달 형식은 자유 — 코드는 붙여넣기, 이미지는 파일 전달이면 되고, frontmatter 기입·파일 배치는 작업자가 수행한다.

## 1. 코드 스니펫 (`implementation.codeSnippet`)

- 프로젝트당 1개, **15~30줄 내외** 권장 (터미널 카드 폭에 맞음. 길면 핵심부로 발췌)
- 함께 필요한 것: 이 코드가 무엇을 보여주는지 **한 줄 설명**(`codeCaption`)
- 클라이언트 소스는 공개 범위를 직접 판단해 주세요 — 식별자·URL·키는 마스킹 가능

## 2. 이미지

파일명·확장자는 자유(PNG로 주면 된다). 배치할 때 **WebP로 변환**해 `public/images/projects/`에 넣고 frontmatter 경로도 함께 맞추므로, 어떤 프로젝트의 어떤 용도인지만 알려주면 된다.

> 현재 등재된 8건은 `.webp`이고, 아직 자료가 없는 `tmon-dashboard`·`yoga-editor`는 frontmatter에 `.jpg` 경로만 적힌 채 파일이 없다. 실존 검증(`imageExists`)을 거치므로 화면은 제목 폴백으로 정상 동작하며, 자료가 오면 `.webp`로 교체된다.
> **개인정보·계정정보·내부 데이터가 보이는 화면은 마스킹 후 전달.**

### 공통 — 프레임과 잘림

카드·캐러셀 모두 **16:10 프레임에 `contain`**으로 담긴다. 즉 **어떤 비율을 주셔도 잘리지 않고**, 프레임과 비율이 다르면 남는 자리가 배경으로 채워진다. 세로로 긴 모바일 앱 캡쳐도 그대로 쓸 수 있다.

- 권장 폭 **1280px 이상** (원본이 클수록 좋다 — 변환 시 줄이는 건 쉽지만 늘릴 수는 없다)
- 가로형(웹 캡쳐)이 프레임을 꽉 채워 가장 보기 좋고, 세로형은 좌우에 여백이 생긴다

### 2-1. Hero 캐러셀 (`carouselImages`) — 상세 페이지 상단 프레임 카드

- 프로젝트당 **1~5장** (1장이면 정지, 2장 이상이면 3초 자동 순환 — 가리키면 멈춘다)
- 클릭하면 라이트박스로 크게 볼 수 있으므로, 화면이 빽빽한 캡쳐도 괜찮다
- 대표 화면·메인 플로우 위주. 순서가 곧 노출 순서다

### 2-2. 카드 대표 이미지 (`image`) — 홈 / `/work` 목록

- 프로젝트당 1장. 캐러셀 첫 장과 같아도 되고 달라도 된다
- **경로와 확장자는 배치 시 실제 변환 결과에 맞춰 frontmatter에 기입한다** (제공자가 신경 쓸 필요 없음)

### 2-3. Demonstrations (`demonstrations[].images`) — 기능 흐름 시연

> 현재는 **추가 자료를 받지 않기로 결정**했다. Hero 캐러셀이 여러 장을 순환하고 라이트박스 확대까지 지원해 시연 역할을 흡수했고, 기능 설명은 Key Features가 담당한다. 아래는 나중에 이 섹션을 쓰게 될 때를 위한 기록이다.

- 데모 항목당 **1~5장** (2장 이상이면 자동 순환)
- 데모 단위 = "하나의 사용 흐름" (예: 검색→상세→결과). 이미지와 함께 흐름 설명 불릿·결과 한 줄이 있으면 이상적

## 3. 우선순위 — 남은 것

대표이미지가 아직 없는 곳은 **`yoga-editor` · `tmon-dashboard` 둘뿐**이다. 나머지 8건은 확보·배치가 끝났다.

- `yoga-editor` — 홈 노출(`FEATURED_SLUGS`)에서는 빠져 있지만 `/work` 목록과 상세에는 나온다. 기존 캡쳐는 품질 문제로 미사용 결정했으므로 대표 이미지를 별도 제작하거나 재캡쳐가 필요하다
- `tmon-dashboard` — 사내 프로젝트라 재캡쳐가 어렵다. 확보가 불가능하면 제목 폴백으로 두어도 페이지는 정상 동작한다

코드 스니펫은 §1의 채택 5건이 모두 반영됐고, 미채택 5건은 슬롯을 비워 해당 영역이 렌더링되지 않는다.
